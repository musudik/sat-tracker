🔌 APIs & Data Sources
N2YO.com
Real-time satellite TLE data, visual pass predictions, and orbital elements. Powers satellite position tracking and pass forecasting in this app.
CelesTrak
Dr. T.S. Kelso's authoritative catalog of NORAD two-line element sets used for orbital propagation. The gold standard for satellite tracking data.
Space-Track.org
US Space Command's official satellite catalog — upstream source for TLE data distributed through N2YO and CelesTrak.
📦 Open Source Libraries
Leaflet.js
Lightweight, mobile-friendly interactive maps. Renders the world map with satellite markers, day/night terminator, and country overlays.
satellite.js
SGP4/SDP4 orbital propagation library. Calculates real-time lat/lng/altitude from TLE data entirely client-side — no API call needed for positions.
Orbitron & Share Tech Mono
Google Fonts powering the sci-fi aesthetic. Orbitron for headers, Share Tech Mono for data readouts.
☁️ Infrastructure
Vercel
Serverless hosting platform. Serves this static dashboard and provides the N2YO API proxy function that keeps the API key secure and solves CORS.
OpenStreetMap
Tile data behind the Leaflet map. Community-maintained geographic data used under the Open Database License.
🤖 Built With Hermes Agent
Hermes Agent — Nous Research
This entire application — map, Kanban board, HUD, satellite data, day/night terminator, icons, and deployment pipeline — was designed and built through conversation with Hermes Agent. The Kanban board in the Countries view is a live demo of Hermes's built-in Kanban task management feature.
